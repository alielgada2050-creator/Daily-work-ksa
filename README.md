# وصلة عمل — منصة التوظيف وتوريد الكوادر

منصة عربية أولًا (RTL) تربط الباحثين عن عمل بالشركات الكبرى والمنشآت الصغيرة وموردي الكوادر. السوق التجريبي: الرياض.
النسخة 0.1 تعمل كاملة **ببيانات وهمية وخدمات محاكاة** دون أي حسابات خارجية، وتتحول للتشغيل الفعلي بتغيير متغيرات البيئة.

> كل الأسماء والأرقام والوثائق والمنشآت في البيانات التجريبية مصطنعة.

## التشغيل السريع (محاكاة كاملة)
```bash
npm install
npm start            # http://localhost:3000  — قاعدة ذاكرة + بيانات طلب الـ100 كهربائي
npm test             # 19 اختبار (قبول + تكامل واتساب)
```
اضغط «تسجيل الدخول» وجرّب الحسابات التجريبية:

| الحساب | الدور | ماذا يجرّب |
|---|---|---|
| فهد — المعتمد النهائي | شركة كبرى / معتمد | اعتماد الطلب، القائمة الأساسية والاحتياطية، الاستبدال، التصدير مع الاتصال |
| سارة — منشئة الطلب | شركة كبرى / منشئ | إنشاء طلب جديد، توثيق التواصل، التصدير الافتراضي |
| خالد — مراجع فني | مراجع فني + مراجع وثائق | «اجتاز فنيًا» / الإرجاع بسبب، الاطلاع على الوثائق |
| يوسف — مسؤول المورد | مورد | رفع دفعة سير، التقدم وإعادة المحاولة، الترشيح، المراسلة |
| نورة — مسؤولة الورشة | منشأة صغيرة (دور واحد مخوّل) | مراجعة واعتماد بدور واحد |
| محمد عبدالرحمن (باحث) | باحث عن عمل | مراجعة حقول السيرة وتصحيحها، الوثائق، سحب الموافقة |
| مدير المنصة | إدارة | التحقق اليدوي، التكرار، البلاغات، سجل التدقيق |
| عمر — شركة أخرى | شركة منفصلة | التأكد من رفض الوصول بين المؤسسات |

## التشغيل على PostgreSQL
```bash
cp .env.example .env          # عدّل DATABASE_URL و SESSION_SECRET
npm start                     # يطبق الهجرات تلقائيًا، ويزرع البيانات التجريبية إن كانت القاعدة فارغة و DEMO_MODE=true
# أو بالحاويات:
docker compose up -d --build  # التطبيق على 127.0.0.1:3000 + PostgreSQL 16
```
النسخ الاحتياطي والاستعادة: `DATABASE_URL=... ./scripts/backup.sh` (طريقة الاستعادة داخل الملف).

## الرفع على GitHub
```bash
git init && git add . && git commit -m "وصلة عمل v0.1"
git branch -M main
git remote add origin https://github.com/<حسابك>/wasla-amal.git
git push -u origin main
```
ملف `.github/workflows/ci.yml` يشغّل الاختبارات تلقائيًا على قاعدة ذاكرة وعلى PostgreSQL 16 مع كل رفع، ويتحقق أن خريطة المعمارية محدثة. `.env` مستثنى من الرفع.

## الخريطة المعمارية (للتعديل لاحقًا)
- `architecture/ARCHITECTURE.md` الشرح والمخطط، و`architecture/graph.json` الرسم المعرفي لكل الأجزاء.
- كل قسم في الكود يحمل معرّفه: `grep -rn "\[MOD-REPORTS\]" src public`.
- قبل أي تعديل: `npm run impact -- MOD-NOMINATIONS 2` يسرد الأجزاء المتأثرة وأماكنها.

## إعداد الخدمات الفعلية
| الخدمة | المتغيرات | الحالة الآن | للتفعيل |
|---|---|---|---|
| **تحليل السير بالذكاء الاصطناعي** | `AI_PROVIDER=openai_compatible`, `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` | جاهز في الكود؛ الافتراضي استخراج محلي | **FreeLLMAPI**: `git clone https://github.com/tashfeenahmed/freellmapi && cd freellmapi && cp .env.example .env && docker compose up -d` ← افتح `http://localhost:3001` وأضف مفاتيح المزودين المجانية وانسخ المفتاح الموحد ← `AI_BASE_URL=http://localhost:3001/v1`, `AI_MODEL=auto`. أو أي مزود متوافق مع OpenAI |
| OCR للسير الممسوحة | `OCR_PROVIDER=tesseract` | معطّل؛ الملف المصوَّر يظهر «تعذرت القراءة» مع زر إعادة المحاولة | `npm i tesseract.js` (الصور مباشرة؛ ملفات PDF الممسوحة تحتاج تحويل الصفحات لصور — متبقٍ) |
| PostgreSQL | `DATABASE_URL` | مختبر على PostgreSQL 16 | قاعدة مُدارة (Neon/Supabase/RDS) أو docker compose |
| التحقق OTP | `OTP_PROVIDER` | محاكاة | تنفيذ مزود (Twilio Verify / Unifonic / Taqnyat) في `src/providers/index.js#otp` |
| التخزين | `STORAGE_PROVIDER`, `STORAGE_DIR` | قرص محلي خاص + روابط موقعة مؤقتة | لإنتاج متعدد الخوادم: S3/R2 بنفس الواجهة |
| **واتساب للأعمال** | `WHATSAPP_PROVIDER=cloud_api` + المتغيرات في القسم التالي | **منفّذ ومختبر** مع خادم Graph محاكى؛ الافتراضي محاكاة + رابط `wa.me` يدوي | اتبع «ربط واتساب للأعمال» أدناه |
| SMS | `SMS_PROVIDER` | محاكاة | مزود يدعم السعودية مع تسجيل اسم المرسل (Sender ID) |
| البريد | `EMAIL_PROVIDER=smtp` أو `gmail_oauth` | محاكاة | SMTP/خدمة إرسال، أو Gmail OAuth بعد ربط الحساب |
| تيليجرام | `TELEGRAM_PROVIDER`, `TELEGRAM_BOT_TOKEN` | محاكاة | بوت من BotFather؛ الإرسال فقط لمن بدأ المحادثة واشترك |

> **أمان FreeLLMAPI:** أبقه على `127.0.0.1`، احذف ملف `.claude/settings.local.json` من مستودعه قبل فتحه بأدوات البرمجة، وحدّثه (`npm audit fix`). نص السيرة يُرسل للنموذج مسوّرًا كبيانات، والنموذج لا يرى أي مفاتيح أو أدوات، ويُفحص ناتجه قبل الحفظ.

## ربط واتساب للأعمال (WhatsApp Cloud API)
1. **Meta Business:** أنشئ تطبيقًا من نوع Business في developers.facebook.com وأضف منتج WhatsApp، واربط رقم الأعمال (رقم غير مستخدم في تطبيق واتساب العادي) وأكمل توثيق النشاط التجاري.
2. **المفاتيح:** من WhatsApp Manager انسخ `Phone number ID` إلى `WHATSAPP_PHONE_ID`. أنشئ System User برمز وصول دائم بصلاحيتي `whatsapp_business_messaging` و`whatsapp_business_management` وضعه في `WHATSAPP_TOKEN`. من إعدادات التطبيق انسخ `App Secret` إلى `WHATSAPP_APP_SECRET`.
3. **القوالب:** الرسائل التي تبدأها المنصة تحتاج قوالب معتمدة من Meta (فئة Utility، لغة ar). أنشئ قالبًا لكل نوع بالمتغيرات بهذا الترتيب، ثم اكتب اسمه في المتغير المقابل:

| المتغير | المتغيرات داخل القالب | مثال نص |
|---|---|---|
| `WHATSAPP_TEMPLATE_INVITE` | {{1}} الاسم، {{2}} الطلب، {{3}} المدينة | مرحبًا {{1}}، رُشّحت لطلب «{{2}}» في {{3}}. افتح ملفك في وصلة عمل للرد. |
| `WHATSAPP_TEMPLATE_AVAILABILITY` | {{1}} الاسم، {{2}} تاريخ المباشرة | مرحبًا {{1}}، هل ما زلت متاحًا للمباشرة بتاريخ {{2}}؟ |
| `WHATSAPP_TEMPLATE_INTERVIEW` | {{1}} الاسم، {{2}} الطلب، {{3}} الموعد | مرحبًا {{1}}، موعد مقابلتك لطلب «{{2}}»: {{3}}. |
| `WHATSAPP_TEMPLATE_MISSING_DOC` | {{1}} الاسم | مرحبًا {{1}}، ينقص ملفك مستند مطلوب. ارفعه من صفحة ملفك. |
| `WHATSAPP_TEMPLATE_START_CONFIRM` | {{1}} الاسم، {{2}} الموقع، {{3}} التاريخ | مرحبًا {{1}}، تم تأكيد مباشرتك في {{2}} بتاريخ {{3}}. |

   القالب غير المربوط لا يُرسل أبدًا؛ تظهر رسالة واضحة باسم المتغير الناقص.
4. **Webhook للحالات:** في إعدادات WhatsApp ← Configuration ضع `https://<نطاقك>/api/webhooks/whatsapp` واكتب في Verify token نفس قيمة `WHATSAPP_VERIFY_TOKEN`، ثم اشترك في حقل `messages`. يتحقق الخادم من توقيع `X-Hub-Signature-256` ويرفض أي طلب غير موقّع.
5. شغّل بـ `WHATSAPP_PROVIDER=cloud_api`. في «التواصل والإشعارات» يظهر لكل دفعة: قبلها المزود ← أُرسل ← تم التسليم ← قُرئ، أو فشل مع رمز الخطأ. لا تُعرض «أُرسل» أو «تم التسليم» إلا بعد وصول تأكيد Meta.

**ملاحظات:** الإرسال فقط لمن لديه موافقة نشطة على قناة واتساب؛ مفتاح الدفعة يمنع تكرار الإرسال حتى لو ضُغط الزر مرتين أو أُعيدت المحاولة؛ تحاسب Meta على المحادثات حسب فئة القالب والدولة؛ رسائل الرد الحر تصح فقط خلال 24 ساعة من آخر رسالة للمرشح.

## المتبقي قبل الإطلاق
1. إدخال مفاتيح Meta واعتماد القوالب لتشغيل واتساب فعليًا، ثم ربط OTP وSMS والبريد وتيليجرام.
2. واجهة إنجليزية كاملة (LTR) بملفات ترجمة.
3. OCR لملفات PDF الممسوحة (تحويل الصفحات لصور) وتشغيل الطابور في عامل منفصل (BullMQ/pg-boss) بدل الذاكرة.
4. مهمة مجدولة لتطبيق سياسة الاحتفاظ والحذف (`retentionMonths` محفوظة في إعدادات السوق).
5. تخزين S3/R2 وفحص الملفات من الفيروسات.
6. واجهة إدارة لتعديل إعدادات السوق (الـAPI جاهز) والصلاحيات وأعضاء المؤسسات.
7. مراجعة قانونية لسياسة الخصوصية والموافقات وفق نظام حماية البيانات الشخصية السعودي، واعتماد متطلبات أهلية العمل لكل سوق.
8. HTTPS ونطاق، و`DEMO_MODE=false`، و`SESSION_SECRET` ثابت، ونسخ احتياطي مجدول.
